# Rescate Sabor

Plataforma para rescatar comida y reducir el desperdicio alimentario.

## Setup rápido

1. `npm install`
2. Copia `.env.example` → `.env` y agrega tus credenciales de Supabase
3. Ejecuta `supabase/schema.sql` en el SQL Editor de Supabase
4. `npm run dev` → abre http://localhost:3000

Ver `CLAUDE.md` para documentación completa.
